## 🚀 Status do Projeto
O Spec Wizard mantém o estado do projeto sincronizado. Use os comandos abaixo no seu terminal integrado para atualizar este conhecimento:

- `wz roadmap`: Ver o progresso atual.
- `wz sync`: Sincronizar este Hub com o código.
